## 发现并修复的问题

1. vendor `AppServerClient` 默认启动参数 `-c mcp_servers.codex-supervisor.enabled=false` 在 codex 0.153.4 下导致 app-server 退出（"invalid transport"）。接入时必须显式设置 `CODEX_APP_SERVER_ARGS`（至少 `["app-server"]`）。
2. ZCode 插件三处协议硬伤已修复（plugin.json 字段名、hooks.json 事件 schema、zcode.mjs JSON 输出），依据 docs/research/2026-09-11-zcode-hook-protocol.md。
